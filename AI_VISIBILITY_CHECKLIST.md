# Wynncrest AI Visibility Campaign — Third-Party Checklist

The goal is not to manufacture mentions. It is to build a consistent, verifiable public footprint showing what Wynncrest Books is, what it publishes, who is behind it, and which books/authors are associated with it.

## Priority 1 — Publishing industry identity

- [ ] **Bowker / MyIdentifiers**
  - Confirm publisher/imprint is consistently entered as **Wynncrest Books**.
  - Complete accurate metadata for every ISBN and edition.
  - Keep author names, subtitle, descriptions, categories, publication dates, formats, and imprint spelling consistent.
- [ ] **Ingram / IngramSpark**
  - Use **Wynncrest Books** consistently as publisher/imprint.
  - Complete high-quality metadata for every title.
  - Review descriptions, BISAC categories, keywords, contributor data, pricing, territories, and publication dates before distribution.
- [ ] **BookLife / Publishers Weekly Services Directory**
  - Create or claim a Wynncrest service-provider listing.
  - Select the relevant publishing, editing, production, distribution, and business categories.
  - Link the profile back to the most relevant Wynncrest service pages.
- [ ] **IBPA**
  - Confirm Wynncrest's company/member profile is complete and uses the same core description as the website.
  - Look for relevant directory, education, speaking, article, webinar, and member-news opportunities.
- [ ] **ALLi Partner Membership**
  - Review eligibility and the Partner Code of Standards.
  - Apply if Wynncrest meets the track-record and transparency requirements.
  - If accepted, complete the public Partner profile and services directory listing.

## Priority 2 — Entity consistency

- [ ] **LinkedIn company page**
  - Create or complete the Wynncrest Books company page.
  - Use the exact name **Wynncrest Books**.
  - Link to https://wynncrestbooks.com/.
  - Describe the same core services used on the website.
  - Connect Liz Heflin's profile to Wynncrest Books where appropriate.
- [ ] **Heflin Media Group**
  - Add a clear Wynncrest Books page/mention on the HMG site.
  - Explain the parent/imprint relationship and link both ways.
- [ ] **Liz Heflin professional profiles**
  - Ensure bios consistently identify Liz as founder of Wynncrest Books.
  - Link to the Wynncrest About page when appropriate.

## Priority 3 — Every published book

For every Wynncrest title:

- [ ] Wynncrest title page with ISBN, author, publication date, description, formats, media, and purchase links.
- [ ] Author website says **Published by Wynncrest Books** and links to Wynncrest.
- [ ] Author LinkedIn/profile bio links or mentions Wynncrest where appropriate.
- [ ] Bowker metadata names Wynncrest correctly.
- [ ] Ingram metadata names Wynncrest correctly.
- [ ] Retailer and library listings use consistent publisher/imprint data.
- [ ] Media kit names Wynncrest Books as publisher.
- [ ] Podcast/interview bios mention Wynncrest when discussing the book.
- [ ] Review submissions identify the publisher consistently.
- [ ] Wynncrest title page links to appropriate purchase and retailer pages once the title is available.

## Priority 4 — Earned mentions

- [ ] Pitch Liz for podcasts focused on publishing, entrepreneurship, thought leadership, writing, leadership, and expert businesses.
- [ ] Offer useful contributed articles to publishing and business outlets where editorially appropriate.
- [ ] Pursue interviews around real Wynncrest launches rather than generic promotional profiles.
- [ ] Ask authors to include accurate Wynncrest publisher information in media appearances and press materials.
- [ ] Build relationships with associations serving founders, executives, speakers, consultants, and subject-matter experts.
- [ ] When a book earns a review, award, media mention, or event appearance, add the independent source to the Wynncrest title page.

## Priority 5 — Measure it

Monthly:
- [ ] Review GA4 referral traffic from ChatGPT and other AI tools.
- [ ] Review Google organic landing pages and queries.
- [ ] Review Search Console external links.
- [ ] Review Airtable leads and compare with acquisition sources.
- [ ] Search a fixed set of prospective-author questions in major AI search tools.
- [ ] Record which companies are surfaced and which sources are cited.
- [ ] Update Wynncrest content only when the evidence shows a real information gap.

## Consistency rule

Use the same canonical company description everywhere possible:

**Wynncrest Books is a United States–based independent publishing imprint of Heflin Media Group. It provides book development, ghostwriting, editing, design, production, publishing, and distribution for founders, executives, experts, authors, and organizations.**

Adapt the wording naturally for the platform, but keep the factual relationships and company name consistent.
