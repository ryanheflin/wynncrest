# Adding an article to the Wynncrest Guide

The Guide is generated automatically from Markdown files in this folder. You do **not** need to edit the Guide page when a new article is added.

1. Duplicate `ARTICLE_TEMPLATE.md`.
2. Rename it with a short lowercase slug, for example:
   `how-to-choose-a-ghostwriter.md`
3. Complete the front matter at the top.
4. Replace the template body with the article.
5. Commit the file to `main`.

GitHub Pages/Jekyll will publish it at:

`https://wynncrestbooks.com/articles/how-to-choose-a-ghostwriter/`

and it will automatically appear on:

`https://wynncrestbooks.com/guide/`

Use Markdown headings beginning at `##` inside articles because the page title is already the H1.

Recommended categories:
- Starting a Book
- Writing & Ghostwriting
- Editing & Production
- Publishing & Distribution
- Author Strategy
